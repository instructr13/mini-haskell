# mini-haskell

A Haskell interpreter written by Haskell.

It uses Term Rewriting Systems to compute any Haskell code.
See [the book](https://doi.org/10.1017/CBO9781139172752) for more details about Term Rewriting.

## Building

```bash
$ stack build
```

## Running

```bash
$ stack run
```

## Testing

```bash
$ stack test
```
